# Ecommerce Arabic glossary (en + ar)

Official terms for this storefront. If a translation differs, **this file wins**.
Modern Standard Arabic. Concise UI labels. Not literal English.

Buttons use **noun form**: Save حفظ · Edit تعديل · Delete حذف · Create إنشاء · Add إضافة · Update تحديث · View عرض.

Success messages begin with **تم**. Do not translate brand names (Stripe, Google, Route).

## Owner / agent

Not used as CRM roles in this app. Logged-in shopper = **المستخدم** or **الحساب**. Do not use وكيل.
